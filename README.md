# Ready Guacamole Server

Apache Guacamole tabanlı uzak masaüstü erişim sunucusu.

## Özellikler

- 🌐 Web tabanlı uzak masaüstü erişimi
- 🖥️ Guacamole Server altyapısı
- 🔐 Kullanıcı kimlik doğrulama
- 📡 Uzak bağlantı desteği
- ⚙️ Sunucu yapılandırması

## Gereksinimler

- Apache Guacamole
- guacd
- Java
- Gerekli bağlantı protokolleri

## Kurulum

Projeyi indirin ve yapılandırma dosyalarını kendi sunucunuza göre ayarlayın.

## Güvenlik

Şifre, API anahtarı, `.env` veya başka gizli bilgileri repository'ye yüklemeyin.
